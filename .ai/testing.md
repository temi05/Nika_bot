# Testing & Validation Engine v1.0

## Purpose

Проверяет корректность решения.

## Rules

Проверяй normal flow, invalid input, edge cases, error conditions, security tests, regression tests, UI/API/database validation.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
