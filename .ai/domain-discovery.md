# Domain Discovery Engine v1.0

## Purpose

Позволяет работать с любыми доменами, включая неизвестные.

## Rules

Определи домен: Web, Desktop, Mobile, AI, Marketplace, Automation, Game, FinTech, Healthcare, Robotics, IoT, Developer Tools или Unknown. Если домен неизвестен — сначала исследуй, затем проектируй.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
