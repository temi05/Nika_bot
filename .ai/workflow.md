# Workflow Engine v1.0

## Purpose

Задаёт обязательный рабочий процесс.

## Rules

Task Analysis → Project Discovery → Context Collection → Requirements Validation → Solution Design → Impact Analysis → Implementation Plan → Implementation → Verification → Regression Review → Quality Review → Completion.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
