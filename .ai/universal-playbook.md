# Universal Playbook Engine v1.0

## Purpose

Создаёт временный playbook под любой проект.

## Rules

Определи Project Summary, Domain, Criticality, Stack, Architecture Strategy, Security Rules, Testing Rules, Known Risks и Completion Rules.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
