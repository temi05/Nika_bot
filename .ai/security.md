# Security Engine v1.0

## Purpose

Безопасность по умолчанию.

## Rules

Zero Trust, input validation, authentication, authorization, least privilege, secret management, file security, database security, API security, safe logging.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
