# Debugging & Root Cause Engine v1.0

## Purpose

Ищет первопричины ошибок, а не маскирует симптомы.

## Rules

Симптом → Воспроизведение → Локализация → Причина → Подтверждение → Исправление → Проверка → Регрессии.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
