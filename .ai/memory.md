# Project Memory Engine v1.0

## Purpose

Сохраняет инженерный контекст проекта.

## Rules

Учитывай архитектурные решения, отклонённые альтернативы, предпочтения пользователя, историю изменений и единый стиль проекта.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
