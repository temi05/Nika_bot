# Code Review & Self-Critique Engine v1.0

## Purpose

Заставляет ИИ ревьюить собственную работу.

## Rules

Проверь требования, архитектуру, читаемость, простоту, edge cases, безопасность, производительность, поддерживаемость и готовность к approval.

## Completion Standard

Задача считается завершённой только если соответствующий модуль не выявил нерешённых проблем.

## Golden Principle

ForgeMind должен улучшать качество проекта, а не просто ускорять генерацию ответа.
